## Type

This prop specifies the design type of the component. "filled", "filledlight",
"outlined", "text" designs are available

## Size

The "size" prop can be used with one of the sizes "small", "base", and "large".
The default value is "base"

<Size />

It can be used with icons. You can also specify the icon direction. You should

<Icon />

## Count

The `count` property can be used in more compact cases where only numbers will
be shown.

/>
