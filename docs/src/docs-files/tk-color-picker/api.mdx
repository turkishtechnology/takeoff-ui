### Events {#color-picker-events}

| Name | Description |
| ---- | ----------- |
| tk-apply | Emitted when the apply button is clicked |
| tk-cancel | Emitted when the cancel button is clicked |
| tk-change | Emitted when the color is applied/confirmed |
| tk-close | Emitted when the panel closes |
| tk-open | Emitted when the panel opens |

### Methods {#color-picker-methods}

| Name | Type | Description |
| ---- | ---- | ----------- |
| apply | <code>apply() =\> Promise\<void\></code> | Applies the current color selection and closes the panel Use this method in custom footer actions |
| cancel | <code>cancel() =\> Promise\<void\></code> | Cancels the color selection, reverts to previous value, and closes the panel Use this method in custom footer actions |
| close | <code>close() =\> Promise\<void\></code> | Closes the color picker panel |
| getValue | <code>getValue(format?: "hex" \| "rgba") =\> Promise\<string\></code> | Gets the current color value in the specified format |
| open | <code>open() =\> Promise\<void\></code> | Opens the color picker panel |

### Slots {#color-picker-slots}

| Name | Description |
| ---- | ----------- |
| footer | Custom footer template (replaces default footer container). |
| footer-actions | Custom actions template for footer layout with styled container. |
| header | Custom header template (replaces default header completely). |
| header-actions | Custom actions template for header (replaces close button). |
