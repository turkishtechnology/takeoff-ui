# Takeoff UI - React Integration Guide

## Overview

Takeoff UI is a Stencil.js web component library. The `@takeoff-ui/react`
package provides native React wrappers around these web components, giving you
proper React event binding, type safety, and idiomatic JSX usage.

All components use Shadow DOM encapsulation. Custom events carry the `tk-`
prefix and deliver data through `event.detail`.

---

## Installation

```bash
npm install @takeoff-ui/react @takeoff-ui/core
```

---

## Setup

Import the core CSS in your application entry point (e.g., `main.tsx`,
`index.tsx`, or `App.tsx`):

```tsx
// main.tsx or index.tsx
import '@takeoff-ui/core/dist/core/core.css';
import React from 'react';
import ReactDOM from 'react-dom/client';
import App from './App';

ReactDOM.createRoot(document.getElementById('root')!).render(<App />);
```

Without this CSS import, components will render without styles.

---

## Importing Components

Import components individually using PascalCase names:

```tsx
import {
  TkButton,
  TkInput,
  TkSelect,
  TkDialog,
  TkTable,
} from '@takeoff-ui/react';
```

---

## Props

Props use **camelCase** naming, matching standard React conventions. Pass
objects and arrays directly as JSX props.

### Common Prop Patterns

| Prop      | Values                                                                                              | Description    |
| --------- | --------------------------------------------------------------------------------------------------- | -------------- |
| `size`    | `"small"` \| `"base"` \| `"large"`                                                                  | Component size |
| `variant` | `"primary"` \| `"secondary"` \| `"neutral"` \| `"danger"` \| `"warning"` \| `"success"` \| `"info"` | Color variant  |
| `type`    | `"filled"` \| `"elevated"` \| `"outlined"` \| `"text"`                                              | Visual style   |

```tsx
<TkButton size="large" variant="primary" type="filled">
  Submit
</TkButton>

<TkButton size="small" variant="danger" type="outlined">
  Delete
</TkButton>
```

### Passing Complex Props

Objects and arrays are passed directly by reference:

```tsx
const columns = [
  { field: 'name', header: 'Name' },
  { field: 'email', header: 'Email' },
];

const data = [
  { name: 'Alice', email: 'alice@example.com' },
  { name: 'Bob', email: 'bob@example.com' },
];

<TkTable columns={columns} data={data} />;
```

## Events

Takeoff UI custom events use the `onTk[EventName]` format in React. The handler
receives a `CustomEvent`, and data is available on `event.detail`.

### Event Naming Convention

| Web Component Event | React Prop   |
| ------------------- | ------------ |
| `tk-click`          | `onTkClick`  |
| `tk-change`         | `onTkChange` |
| `tk-blur`           | `onTkBlur`   |
| `tk-focus`          | `onTkFocus`  |
| `tk-input`          | `onTkInput`  |
| `tk-select`         | `onTkSelect` |
| `tk-close`          | `onTkClose`  |

### Event Handler Signature

```tsx
const handleChange = (e: CustomEvent) => {
  const value = e.detail; // Access event data here
  console.log('New value:', value);
};

<TkInput onTkChange={handleChange} />;
```

## Slots

Use the `slot` attribute on child elements to project content into named slots:

```tsx
<TkDialog>
  <div slot="header">Dialog Title</div>
  <div slot="content">
    <p>This is the dialog body content.</p>
  </div>
  <div slot="footer">
    <TkButton variant="primary">Confirm</TkButton>
    <TkButton variant="neutral">Cancel</TkButton>
  </div>
</TkDialog>
```

Default slot content (no `slot` attribute) fills the unnamed default slot:

```tsx
<TkButton>Click Me {/* default slot */}</TkButton>
```

---

## TypeScript Support

The React wrappers include full TypeScript definitions generated by the Stencil
output target. Props, events, and component types are all strongly typed.

```tsx
import { TkInput } from '@takeoff-ui/react';

// Props and events are fully typed
<TkInput
  value={name}
  placeholder="Enter your name"
  size="base"
  onTkChange={(e: CustomEvent<string>) => setName(e.detail)}
/>;
```

## Common Examples

### Button

```tsx
import { TkButton } from '@takeoff-ui/react';

function ButtonExample() {
  const handleClick = (e: CustomEvent) => {
    console.log('Button clicked');
  };

  return (
    <div>
      <TkButton variant="primary" type="filled" onTkClick={handleClick}>
        Primary Action
      </TkButton>

      <TkButton variant="secondary" type="outlined" size="small">
        Secondary
      </TkButton>

      <TkButton variant="danger" type="filled" disabled>
        Disabled
      </TkButton>
    </div>
  );
}
```

### Input with Controlled State

```tsx
import { useState } from 'react';
import { TkInput } from '@takeoff-ui/react';

function InputExample() {
  const [name, setName] = useState('');
  const [email, setEmail] = useState('');

  return (
    <form>
      <TkInput
        label="Name"
        value={name}
        placeholder="Enter your name"
        onTkChange={(e: CustomEvent) => setName(e.detail)}
      />

      <TkInput
        label="Email"
        value={email}
        placeholder="Enter your email"
        type="email"
        onTkChange={(e: CustomEvent) => setEmail(e.detail)}
        onTkBlur={() => console.log('Email field lost focus')}
      />

      <p>
        Hello, {name}! Your email is {email}.
      </p>
    </form>
  );
}
```

### Select

```tsx
import { useState } from 'react';
import { TkSelect } from '@takeoff-ui/react';

function SelectExample() {
  const [selected, setSelected] = useState('');

  const options = [
    { label: 'Option A', value: 'a' },
    { label: 'Option B', value: 'b' },
    { label: 'Option C', value: 'c' },
  ];

  return (
    <TkSelect
      label="Choose an option"
      options={options}
      value={selected}
      onTkChange={(e: CustomEvent) => setSelected(e.detail)}
    />
  );
}
```

### Table

```tsx
import { TkTable } from '@takeoff-ui/react';

function TableExample() {
  const columns = [
    { field: 'id', header: 'ID' },
    { field: 'name', header: 'Name' },
    { field: 'status', header: 'Status' },
  ];

  const data = [
    { id: 1, name: 'Task A', status: 'Active' },
    { id: 2, name: 'Task B', status: 'Completed' },
    { id: 3, name: 'Task C', status: 'Pending' },
  ];

  const handleRowSelect = (e: CustomEvent) => {
    console.log('Selected row:', e.detail);
  };

  return <TkTable columns={columns} data={data} onTkSelect={handleRowSelect} />;
}
```

### Dialog

```tsx
import { useState } from 'react';
import { TkButton, TkDialog } from '@takeoff-ui/react';

function DialogExample() {
  const [open, setOpen] = useState(false);

  return (
    <>
      <TkButton variant="primary" onTkClick={() => setOpen(true)}>
        Open Dialog
      </TkButton>

      <TkDialog open={open} onTkClose={() => setOpen(false)}>
        <div slot="header">Confirm Action</div>
        <div slot="content">
          <p>Are you sure you want to proceed?</p>
        </div>
        <div slot="footer">
          <TkButton variant="primary" onTkClick={() => setOpen(false)}>
            Confirm
          </TkButton>
          <TkButton variant="neutral" onTkClick={() => setOpen(false)}>
            Cancel
          </TkButton>
        </div>
      </TkDialog>
    </>
  );
}
```

## Gotchas and Common Mistakes

### 1. Always access `event.detail` for event data

Takeoff UI events are `CustomEvent` instances. Do **not** use
`event.target.value` like you would with native HTML inputs.

```tsx
// WRONG
const handleChange = (e: any) => {
  setValue(e.target.value);
};

// CORRECT
const handleChange = (e: CustomEvent) => {
  setValue(e.detail);
};
```

### 2. Object and array props are passed by reference

If you mutate an object or array that was passed as a prop, the component may
not detect the change. Always create new references when updating:

```tsx
// WRONG - mutating in place
data.push(newItem);
setData(data);

// CORRECT - new array reference
setData([...data, newItem]);
```

### 3. CSS import is required

Without the core CSS import, components will render but appear unstyled:

```tsx
// This MUST be in your app entry point
import '@takeoff-ui/core/dist/core/core.css';
```

### 4. Shadow DOM encapsulation

Components use Shadow DOM. You cannot target internal elements with global CSS.
Use the component's props (e.g., `variant`, `size`, `type`) and CSS custom
properties to customize appearance.
